宿主 C++ 测试用的是系统 g++ 13.3.0。Debug 和 Release（定义了 `NDEBUG`）都跑过，包含 V2.1 的拟合和路由检查。检查用的是普通 `if`，不是 `assert()`，所以 Release 里断言被拿掉以后测试仍然有效。NDK Clang 是 19.0.1。这次构建机器的内核是 Linux 6.12.113+，x86_64。

## 安装 SDK

```bash
bash scripts/setup-android-sdk.sh
```

脚本会把 SDK 放到 `$ANDROID_HOME` 或 `~/android-sdk`，并写 `local.properties`。`local.properties` 不进 git。

## 命令

```bash
bash scripts/run-host-tests.sh
export ANDROID_HOME="$HOME/android-sdk"
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Debug APK 在 `app/build/outputs/apk/debug/app-debug.apk`。原生库即使在 Debug 变体也带 `-O2 -fno-fast-math -fno-finite-math-only`，这是从 `compile_commands.json` 里核对过的。fast-math 关掉以后，NaN/Inf 判断才成立。

`lintDebug` 结果：0 个 error，19 个 warning（其中包含“有更新的 Gradle”这一类提示）。

没有连接任何手机或模拟器。仪器测试和声学延迟都没有跑。
