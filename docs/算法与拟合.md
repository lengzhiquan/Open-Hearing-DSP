# 算法、拟合、来源和校准

这是个人音频实验，不是医疗器械，也不是助听器验配。下面的 dB 都是数字满刻度或相对电平。没有声学校准时，不能写成临床 dB HL，也不能说实现了 NAL-NL2 或 DSL。

## 电平定义

测量、拟合和实时检测用同一套分析滤波器：6 段 Linkwitz-Riley 4，分频 **250 / 750 / 1500 / 3000 / 6000 Hz**。正好落在分频点上的频率算下一频段（较低的那一段）。

频段电平是这段滤波器输出的 RMS，标识 `analysisFilterbankBandRms`。纯音的全带 RMS 和这个频段 RMS 不是同一个数。48 kHz 宿主测试里，1000 Hz 纯音校到频段 RMS -30 dB 时，全带比频段大约高 4.0 dB；同样目标的白噪声大约高 18.8 dB。拟合不能把纯音 dBFS 当成宽带语音的频段能量。

测试音默认是啭音：中心频率 ±5%，调制 5 Hz，标识 `warble-5pct-5Hz`。选用它是为了减轻耳道和耳机腔在单频上的尖峰。仍不是临床纯音测听。

## 11 个频点怎么映射

测试频点：125、250、500、750、1000、1500、2000、3000、4000、6000、8000 Hz。

| 分析段 | 包含的测试频点 | 段中心（写入映射） |
| --- | --- | --- |
| 0 | 125、250 | 125 Hz |
| 1 | 500、750 | 433 Hz |
| 2 | 1000、1500 | 1061 Hz |
| 3 | 2000、3000 | 2121 Hz |
| 4 | 4000、6000 | 4243 Hz |
| 5 | 8000 | 8000 Hz |

WDRC 用这 6 段，分频点和上表相同。图示均衡仍是原来的 10 段。各段在参考输入级 **-40 dBFS** 上的增益，按频率的对数插到图示中心。31 Hz、62 Hz、16 kHz 没有测量，增益保持 0 dB，来源是**工程默认**。自动拟合不写 PEQ，避免和图示均衡、WDRC 各补一次。PEQ 只留给手动，来源标**手动修改**。

映射标识写在预设的 `algorithm.mapId` 里。没改记录就不能改这套分频。

## 听阈方法

选定改良 Hughson-Westlake：下行 10 dB，上行 5 dB，同一电平上行 2/3 次听到即记为听阈。标识 `modified-hughson-westlake-10down-5up-2of3`。一次会话里不换方法。

- 起点 -40 dBFS（频段 RMS），先在 1000 Hz 做一次不计入听阈的熟悉。
- 测量输出上限 **-18 dBFS**，比监听安全限幅 **-1 dBFS** 更严。到上限就停，不追不舒适响度。
- 下限 -70 dBFS。底下仍听得到就只记“不高于 -70”，不编一个更低的阈值。
- 大约每 5 次有一次空白试次。反应短于 150 ms 或长于 5 s，试次不可靠。
- 单次会话暴露累计到 12 分钟就停，并提示休息。建议隔天复测；复测不自动覆盖。
- 测量时界面吃掉音量键。若系统音量仍变化，试次条件作废并提示。

## 响度到目标

主观等级 0 到 6 是有序数据。同一电平取中位数，再用保序回归（相邻违例合并）得到不下降的曲线。曲线倒过来，才估计某个等级对应的输出电平。外推不超过已测电平的两端。

参考听众只在相对 dBFS 里定义，来源是**参考目标**，不是听力图：

| 频段 RMS | 参考等级 |
| --- | --- |
| -70 | 1 |
| -55 | 2 |
| -40 | 4 |
| -20 | 5 |

对输入级 -60、-40、-20 dBFS，目标输出是用户曲线上、与参考听众在该输入级同一等级的电平。增益 = 输出 − 输入。数据不够、环境噪声超标、重复性差、非单调、未校准高频，都会把权重乘小。权重很低时增益往 0 dB 收，来源改成**插值**或**工程默认**。

## 联合拟合

总增益拆成两段，避免加两次：

- 图示均衡拿走参考级 -40 dBFS 上的增益。
- WDRC 在这一级的增益凑成 0。比 -40 更弱时增益可以更高，更强时增益下降。

压缩曲线就是实时引擎的 `staticCompressorDb`，膝宽固定 10 dB。搜索阈值和压缩比（自动压缩比不超过 4:1），补偿量由“-40 dBFS 上压缩增益为 0”定死。Attack **10 ms**、Release **150 ms**、Knee **10 dB** 不参与搜索，来源永远是**工程默认**，除非之后手动改，那时标**手动修改**。

离线拟合和“处理器输出是否跟静态曲线一致”都调用这份 C++。宿主测试里，由已知曲线生成的五个电平，反求 RMSE 为 0.000 dB。规格里的三点例子（-60/+18、-40/+12、-20/−2）单膝拟合残差约 3.3 dB，残差被记下来，不假装唯一解。

1000 Hz 正弦经过同一处理器：图示 +3 dB 且检测器用频段 RMS 时，测到的总增益和静态公式一致（这次输入 RMS 约 -37 dBFS，两边都是 3.00 dB）。V1 的峰值检测仍然留给原来的实验压缩，拟合出来的多段才用频段 RMS。

可用增益上限写进约束：未校准且频段中心在 3 kHz 以上时，自动增益不超过 12 dB；若填了实测反馈余量，再减去 6 dB。触发上限会留下约束标记，并降低置信度。

两耳差大约达到 40 dB、用户报告耳鸣/耳痛、或突发变化时，停止加大自动补偿，并提示做专业检查。没有做对侧掩蔽，预设里 `contralateralMaskingUsed` 固定为 false，不能写“已排除交叉听力”。

双耳确认是测完单耳之后的手动平衡和总响度，存成派生记录，不覆盖原始试次。单麦或双麦都不会被说成真实的人头空间信息。

## 麦克风校准三档

校准按输入模式分开：立体声左、立体声右、双麦合成、仅顶部。左右互换只改路由，校正仍打在物理声道上，不另建一套校准。

| 档 | 来源标签 | 处理 |
| --- | --- | --- |
| 未校准默认 | 未校准默认 | 不套任何修正曲线。高频最大增益更紧，置信度更低。 |
| 主观透明度匹配 | 主观匹配 | 用户 A/B 得到的相对曲线。不是声学校准。 |
| 参考麦克风相对校准 | 参考麦克风相对校准 | 只有真的用参考麦录过才能选。立体声要左右各一条，不能用一条代表两个麦。 |

三档都不代替耳机输出的声压校准。手机没有厂家麦校准文件，这是已知限制，不用估计曲线冒充。

## 噪声底和可选频谱降噪

噪声底用同一套分析滤波器的频段 RMS。安静采样得到各段噪声电平后，信噪比低的段会限制 WDRC 的正向增益。限制增益不会提高信噪比。宿主测试里，噪声底设在 -24 dBFS、请求 +18 dB 补偿时，弱正弦的实际增益被压到大约 0 dB。

频谱降噪是 256 点 STFT，50% 重叠，软掩蔽，衰减最多约 6 dB。默认关闭。打开后的算法延迟是 256 样本：48 kHz 上 5.33 ms（宿主冲激峰精确落在第 256 个样本）。这只是模块延迟，不含声卡和声学路径。因此不能说打开之后端到端仍在 10–20 ms 里。真机没测过。

啸叫检测是传统窄带优势判断（大约 3 kHz 以上的一段比其余段高 12 dB 以上并持续约 80 ms），然后最多压低 12 dB。不用神经网络。默认关闭，避免哨声和反馈以外的窄带声被误压。宿主里 4 kHz 大信号会触发，200 Hz 大信号不会。

## 来源标签

只用这五个：**实测推导**、**参考目标**、**插值**、**工程默认**、**手动修改**。麦克风校准只用：**未校准默认**、**主观匹配**、**参考麦克风相对校准**。缺数据就降置信度或标插值/默认，不把空字段写成测出来的。
