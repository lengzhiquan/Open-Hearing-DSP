## 宿主 C++ 

命令：

```bash
bash scripts/run-host-tests.sh
```

等价于用 g++ 13.3.0 分别配置 Debug 和 Release。Release 带 `NDEBUG`。两次输出都以 `ALL TESTS PASSED` 结束。关键测量（两边数字一致）：

- 图示均衡 +6 dB @ 1 kHz：左 +6.0000 dB，右 -6.0000 dB，40 Hz 处 +0.0052 dB。处理器正弦稳态增益 6.000 dB。
- 单段压缩，-6 dBFS 恒定输入，门限 -20 dB，比率 4，硬膝，补偿 0：稳定在 -16.500 dBFS。
- 静态软膝：-10 dBFS 硬膝比 4 得到 -17.5 dBFS；门限上、膝 6 dB、比 4 得到 -20.5625 dBFS。
- 分频 4 到 8 段的脉冲重组误差约 8.2e-7 到 8.5e-7。补偿后正弦幅度误差小于 0.05 dB。未补偿相加在 8 段 10 kHz 达到 -4.396 dB。
- 1 kHz 群延迟：4 段 27.96 样本，5 段 44.25，6 段 48.45，7 段 50.45，8 段 51.78。
- 多段动态染色：相对全旁路重组 -2.097 dB。
- 另外覆盖了 0 dB 直通、+6 dB 增益、静音起步、平滑无阶跃、限幅不超过 -1 dBFS、NaN/Inf 故障静音、环的回绕/溢出/0.1% 漂移有界、双线程环和参数发布、畸形参数拒绝。

V2.1 同一套宿主测试里新增的测量（Debug 与 Release/`NDEBUG` 数字一致）：

- 1000 Hz 纯音校到分析频段 RMS -30 dB 时，全带比频段高 3.97 dB；啭音高 3.91 dB；白噪声高 18.76 dB。
- 双麦相加、8 样本延迟：125 Hz 为 +6.00 dB，3000 Hz 抵消到约 -160 dB。
- 未校准档即使填了 +12 dB 修正曲线，输出仍与不修正一致。参考麦档在 1 kHz 的 +6 dB 修正测到 +6.00 dB。
- 噪声底限控制：请求 +18 dB 补偿、噪声底 -24 dBFS 时，弱正弦增益约 0.00 dB。
- 已知 WDRC 曲线反求 RMSE 0.000 dB。加 ±1.5 dB 扰动后，曲线偏离最多 0.917 dB。规格中的三点例子残差 3.305 dB，已报告而不是当成唯一解。
- 处理器与静态联合增益在这次 1 kHz 正弦上同为 3.00 dB（输入 RMS -36.99 dBFS）。
- 啸叫检测：4 kHz 触发 4 次，压低 12.00 dB；200 Hz 同样幅度不触发。
- 频谱降噪默认路径不加延迟。打开后冲激峰在第 256 个样本，48 kHz 上 5.33 ms。这不是端到端。
- 模式切换和增益切换后样本有限，不超过 -1 dBFS 安全限幅，相邻样本阶跃小于测试门限。
